This project consists of a game based on the classic Bomberman, developed using the MVC (Model-View-Controller) design pattern.

The game features a graphical interface that includes a board of squares with different elements such as a player (represented by a blue square), an enemy (red square) and bombs (black circles). Both characters have three lives, and the goal of the game is to dodge bombs and defeat the enemy.
