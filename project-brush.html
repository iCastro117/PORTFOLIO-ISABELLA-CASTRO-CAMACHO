Brush

A command-line agentic auditor that checks whether a frontend implementation actually matches its design spec. It takes the design and the shipped code, then reports every difference between them — colour drift measured in CIEDE2000, spacing and geometry, typography, and WCAG accessibility defects — grouping findings by root cause, so one broken token reads as one problem instead of twenty unrelated bugs.

Built in pure Python 3.10+ with no third-party dependencies in the core engine, running a six-stage pipeline (Extract, Map, Measure, Diagnose, Verify, Report) in which three stages are LLM agents, checked against a knowledge base of 30 UX laws and 10 usability heuristics. Every finding is deterministic and mathematically provable: across 1,500 seeded errors it reached 1.00 recall with zero false positives.
