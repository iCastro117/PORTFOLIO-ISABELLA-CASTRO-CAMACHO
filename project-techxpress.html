TechXpress

This project is a UX/UI design for “TechXpress”, a fictitious e-commerce platform specializing in tech components and gaming peripherals.

The design uses a bold dark theme with vivid pink accents to appeal to a tech-savvy audience, featuring clear product categories, secure checkout messaging, and a dedicated support section.
